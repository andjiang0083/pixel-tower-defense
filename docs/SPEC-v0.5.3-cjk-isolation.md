## 1. 现状（实测，不是印象）

`v0.5.0（Claw4 移植）` 把中文**整条链路从仓库删掉**，理由是 Claw4 的 720 屏放不下
固定 17px/字 的 16×16 点阵（`src/i18n.h` 头注原话："既然 Claw4 才是当前的真机目标，就把它整条删掉"）。
删掉的（upstream/main=v0.4.4 仍在，可回取）：

| 资产 | 规模 | 现状 |
|---|---|---|
| `src/cn_font.h`（16×16 点阵，95+ 手写位图） | 114 行 / 17.7KB Flash | 已删 |
| `tools/gen_cnfont.py`（从 `i18n.h` 的字符串表生成字库） | 100 行 | 已删 |

**根因不是"公式写错"，是隔离形状**：板级差异（窄屏放不下 CJK）被搬到**共享层**上，
而且用"删功能"实现；`TR()` 的 42 个调用点还在，但表只剩一份 ⇒ Tab5（1280×720，放得下）
跟着一起失去双语。同一批改动还把 Tab5 的构建路径打断了两处（`-I build/tab5`、
`main.cpp` 仍传 `M5GFX*`），已在 v0.5.2 修回。

## 2. 目标形状：能力宏 + 单字库（共享层零板名）

**唯一正确的隔离形状**（与 `esp32-cross-board-porting` §10 一致）：

- 差异由 **profile 提供的「能力宏」**表达，不由板名表达：
  `tools/layout.py` 的 `PROFILES[*]` 加一项 `cjk=True/False` → 生成 `#define PTD_HAS_CJK 0|1`。
  - `tab5 = 1`（1280×720，放得下，也是对外卖点之一）
  - `claw4 = 0`（720×720，窄槽放不下；**将来要开中文，改这一格 + 重排它的 720 布局**）
- 共享层（`i18n.h` / `pixel_text.h` / `render.h`）里**不出现板名**，只出现 `#if PTD_HAS_CJK`。
- **字库真源唯一**：`i18n.h` 的 `STR_CN[]` 与 `tools/gen_cnfont.py` 是同一份真源，
  生成 `src/cn_font.h`（入库）；`PTD_HAS_CJK=0` 的 profile 只是**不 include**它 ⇒
  不改字库、不造第二份表；将来 claw4 要开，改一格即可。
- `PTD_HAS_CJK=0` 时代码形状 = 今天的英文单语形态：`TR()` 直返 `STR_EN[]`，
  `pixel_text.h` 无 CJK 分支，标题界面无语言按钮，NVS 不写 `"lang"`。

## 3. 判据（每一条都要能机判）

1. **Tab5 拿回双语**：tab5 仿真里 `for(lang in {EN,CN})` 跑全部文本适配断言 + 缺字计数器 = 0
   （即：表里每个汉字在 `cn_font.h` 里都有位图，一条不漏）。
2. **claw4 零位移**：`PTD_HAS_CJK=0` 时，claw4 侧编译产物**与本次改动前逐字节相同**
   （阶梯：预处理文本比对 → 不行就 `.obj` 剥 DWARF 比对；镜像 sha 不作判据，含 git describe）。
3. **claw4 仿真基线不降**：仍 320 passed / 0 failed，CI 的 `total>=320 & failed==0` 保持。
4. **Tab5 固件能编能刷**：`pio run -e tab5` 通过 + 刷机 + 开机横幅含 `lang=` + 标题界面语言按钮可见。
5. **门禁治得住"下次再删"**：CI 加两条 —— ①（tab5）`check_cnfont` 覆盖检查；②
   **隔离门禁**：共享层文件里不得出现 `TAB5`/`CLAW4` 之类板名（能力宏之外的板级判断一律红）。

## 5. 风险与取舍（需要用户拍的）

- **claw4 什么时候也开中文**：它的 720 布局放不下固定 17px/字（槽 116px / 面板 202px）。
  要么把中文字库做成**随 scale 缩放**（16×16 → 12×12 需重画字形），要么缩短文案 + 加宽槽。
  **不在本 SPEC 范围内**，但门禁按能力宏立好后，它的开法是"改一格 + 重排它的布局"。
- **Tab5 中文排版回归核验**：v0.4.3 之后标题/面板布局都重排过，中文字宽（17px/字）与英文
  不同 ⇒ 需要按 §3.1 的两语断言逐条过，必要时微调 tab5 的若干 x/y。
- 成本：改动落在 8 个文件 + CI；**claw4 侧要求零位移**（用 §3.2 阶梯证明），Tab5 侧要重刷验证。
