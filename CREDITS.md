# CREDITS / 署名

## Who wrote this game / 这个游戏是谁写的

**Architecture and most of the code were written by a local LLM** — a 4-bit
Qwen3.8-Flash-Next running on the author's own Mac through a local MLX
inference server. A human (and a primary-school playtester) set the goals,
played the builds, and reported back; the local model wrote the game logic,
the map generator, the renderer and the build scripts.

**架构和大部分代码由本机大模型写就** —— 一台 Mac 上跑的 4-bit
Qwen3.8-Flash-Next（本地 MLX 推理）。人负责定目标、玩、反馈；模型负责写
游戏逻辑、地图生成器、渲染和构建脚本。一个额外的事实是：它并不快，
一行行写出来的，这也正是它值得被记下来的原因。

- Author / maintainer: **andjiang0083**
- Playtesting: a primary-school kid (difficulty and wave tuning came from his feedback)
- Sound, art and font: generated by code in this repository (see below) — no downloaded assets

## Assets / 素材

There are **no asset files** in this repository — that is a design constraint,
not an accident:

- `src/pixel_font.h` — 95 glyphs, **hand-written 5×7 bitmaps** (`tools/gen_font.py`).
  No system or third-party font is used, so there is no font license to inherit.
- `src/sfx_data.h` — all sound effects are **synthesised from arithmetic at build
  time** (`tools/gen_sfx.py`): square waves, swept tones and an LFSR noise
  generator. No samples, no sound-font, no audio files.
- Every visual is `fillRect` / `drawPixel` calls (`src/render.h`). No `.bmp`,
  no PNG, no sprite sheet, no tilemap file.
- `tools/mkposter.py` builds the promo art from a real emulator frame plus the
  game's own glyph table and the synthesized PCM — so the poster is "zero
  assets" too.

If you fork this and add real assets, check their licenses yourself.
